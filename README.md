# Ring Sizer — Privacy Policy

_Last updated: 9/18/2026_

Ring Sizer does not collect, store, or share any personal data.

## What we collect

**Nothing.** Ring Sizer has no account system, no analytics, and no backend server. All measurements happen entirely on your device and are never transmitted anywhere.

## Data storage

Any sizing results are kept only in the app's local memory while you use it. Nothing is saved to the cloud, and nothing persists after you close the app.

## Third parties

Ring Sizer does not use any third-party tracking, advertising, or analytics services.

## Children's privacy

Since Ring Sizer collects no data of any kind, it is safe for use by users of any age.

## Changes to this policy

If this policy ever changes, an updated version will be posted here with a new date.

Questions about this policy? Please create an issue in this github respository. Thanks!
